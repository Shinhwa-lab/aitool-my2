- 대상: (가상) 한빛정밀(주) 바이어 150곳 리스크 보드 · 기준일 2026-09-30 · 합성 데이터
- 레퍼런스: `workbench/day3/refs/ref1.png`(Range Rover 한국 사이트 첫 화면) · `ref2.png`(Mercedes-Benz 한국 사이트 첫 화면) — 출처는 `workbench/day3/refs/links.md`
- 원칙: 두 화면의 **구조 · 간격 · 글자 위계만** 따라 한다. **색과 내용은 우리 것**이다.
- 화면을 만들 때 모양은 아래 토큰만 쓴다. 토큰 밖 값이 필요하면 이 파일에 먼저 토큰을 더한다.
- 대표님 요청(`labs/day3/lab-d/ceo_request.md`): 휴대폰에서 한눈에 · 숫자는 정확하게, 꾸밈은 적게 · '우리가 공들여 만든 것처럼'

## 1. 레퍼런스에서 가져올 것 · 가져오지 않을 것

**가져올 것**

1. 맨 위의 얇은 안내 띠 한 줄(ref1) — 우리는 여기에 기준일 · 데이터 범위를 쓴다.
2. 왼쪽 정렬로 이어지는 글자 위계(ref2): 큰 제목 → 짧은 설명 한두 줄 → 큰 숫자 한 줄 → 작은 주석. 이 순서를 KPI 구역에 쓴다.
3. 넉넉한 왼쪽 여백과 구역 사이의 큰 간격, 한 구역에 한 가지 이야기만(ref1 · ref2 공통).

**가져오지 않을 것**

1. 사진 · 영상 배경, 로고 · 브랜드 글자 · 아이콘, 레퍼런스의 문장 — 그림 · 로고 · 글은 가져오지 않는다.
2. 레퍼런스의 색(검은 머리줄 · 브랜드 파랑 단추) — 색은 아래 토큰(우리 것)으로 한다.
3. 알약 모양(완전히 둥근) 단추와 화면에 떠 있는 피드백 · 채팅 단추 — 모서리는 8px 이하, 떠 있는 장식은 두지 않는다.

## 3. 레이아웃 뼈대

v2(C안 매거진 · 보고서형): 카드 상자 대신 구역 위 가는 가로줄, 제목은 명조, 큰 숫자 · 넓은 여백 · 짧은 캡션, 글은 왼쪽 정렬. (v2에서 바뀜)

구역 이름과 순서(두 폭 모두 같다): **머리(제목 · 기준일) → KPI 4개 → 신호등 등급 분포 + 위험 선 슬라이더 → 위험 상위 10 → 지역별 채권 → 바닥글**

### v2 배치 — 2단 매거진 (v2에서 바뀜)

- 1100px 이상: 머리 → KPI 4칸까지는 한 단. 그 아래를 2단으로 나눈다. 왼쪽 넓은 단(2/3)은 위험 상위 10 → 지역별 채권, 오른쪽 좁은 단(1/3)은 위험 선 → 등급 분포를 두고, 오른쪽 단은 스크롤해도 화면 위에 붙어 따라온다(sticky, 위 여백 `--sp-5`). 단 사이 `--sp-7`. (v2에서 바뀜)
- 1099px 이하 · 휴대폰: 한 단으로 머리 → KPI → 위험 선 → 등급 분포 → 위험 상위 10 → 지역별 채권 → 바닥글. (v2에서 바뀜)
- 7개 구역과 숫자 · 슬라이더 규칙은 그대로이고, 놓는 순서와 자리만 바뀐다. 아래 v1 뼈대는 되돌릴 때를 위해 남긴다.

```
┌──────────────────────────────────────────────────────────────┐
│ 기준일 줄 · 제목(명조) · 한 줄 소개 ─────────────────────────── │
│ KPI  [위험 바이어] [C등급 채권] [전체 채권] [연체 금액]          │
├─────────────────────────────────────────┬────────────────────┤
│ 위험 상위 10 (표)                         │ 위험 선 슬라이더     │
│                                         │ 'C등급 +몇 곳'      │
│                                         │────────────────────│
│─────────────────────────────────────────│ 등급 분포 막대 · 표  │
│ 지역별 채권 (막대, C 몫 빨강)              │ ↑ 스크롤해도 따라옴   │
├─────────────────────────────────────────┴────────────────────┤
│ 바닥글                                                         │
└──────────────────────────────────────────────────────────────┘
```

## 4. 'AI 티' 금지 목록

| 금지 | 대신 |
|---|---|
| 보라 · 파랑 그라데이션 | 흰색 · 연회색 바탕 + 강조 1색 |
| 이모지 아이콘 | 글자 라벨, 꼭 필요하면 선 아이콘(SVG) |
| 모든 카드에 그림자 | 1px 테두리나 바탕색 차이 |
| 유리(blur) 효과 남발 | 불투명한 면 |
| 가운데 정렬 일색 | 글은 왼쪽, 숫자는 오른쪽 정렬 |
| 'Welcome back!' 같은 빈말 | 기준일 · 데이터 범위처럼 쓸모 있는 한 줄 |
| 무지개색 차트 | 회색 + 뜻이 있는 1–2색(등급 색) |
| 지나치게 둥근 모서리 | 4–8px |
| 의미 없는 장식 그림 | 빈칸(여백) |
| 영어 더미 글 | 우리말 진짜 문장 |
